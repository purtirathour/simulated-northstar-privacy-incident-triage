# Northstar | Privacy Incident Triage & Document Review

Independent Portfolio Project | Microsoft Excel | Data Privacy & Compliance

## Project Overview

This self-directed project simulates a potential employee-data disclosure at Northstar Solutions Pvt. Ltd., a fictional organisation.

I developed an Excel-based document review framework to classify information, identify potential privacy risks, assess sharing authorisation, document escalations and perform quality-control checks.

All documents and findings are synthetic. This is not a real client engagement or forensic investigation.

## Project Objective

To develop a reproducible framework for privacy incident triage using structured document classification, consistent review rules, escalation tracking and documented quality control.


## Skills Demonstrated

- Data Classification: Personal data, PII, identifiable health information (PHI) and financial information.

- Incident Triage: Assessment of external sharing, recipient authorisation and potential exposure.

- Regulatory Mapping: Educational application of India's DPDP Act and Rules.

- Quality Control: Second-pass review, discrepancy identification and reconciliation.

- Documentation: Review protocol, evidence register, escalation log, findings summary and dashboard.

## Key Findings

| Initial coding agreement | 60% (3 out of 5) |


Escalations represent potential issues requiring verification, not confirmed data breaches.

## Review Methodology

1. Established a standardised document review protocol.
2. Classified 30 synthetic document summaries using defined coding criteria.
3. Assessed potential exposure and recipient authorisation.
4. Documented unresolved issues and recommended follow-up actions.
5. Conducted a five-record second-pass review and reconciled classification differences.
6. Created an Excel dashboard and findings summary.

## Limitations

The review is based on synthetic document summaries, not original emails, attachments or forensic evidence. Unverified information is documented as uncertain.

The second-pass review was performed by the same reviewer; its agreement metric reflects internal coding consistency rather than independent validation.

The DPDP framework is used for educational purposes. Applicable laws and reporting requirements would need to be verified before handling a real incident.
